## Objetivo

Analizar los requerimientos de calidad de software de las plataformas
Stellar y Drips, evaluando su gestión de código abierto, adaptación a un
ecosistema descentralizado, riesgos éticos/de seguridad, y su vínculo
interdisciplinario entre ingeniería de software y economía Web3.

## Estructura del repositorio

- `informe/` — documento final integrado.
- `investigacion/` — notas de investigación de cada integrante, organizadas por criterio de la rúbrica.

## Cómo trabajamos

Cada integrante sube directamente su archivo correspondiente a la rama
`main`, dentro de la carpeta que le corresponde (`investigacion/`), usando la opción "Commit directly to the main branch"
de GitHub.
