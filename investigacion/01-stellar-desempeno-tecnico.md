# 01. Desempeño técnico — Stellar

## 1. Introducción

Stellar es una red blockchain de código abierto orientada a facilitar operaciones relacionadas con activos digitales y transferencias.

Para este proyecto se analiza Stellar como una referencia tecnológica para identificar requisitos de calidad relacionados con seguridad, fiabilidad, trazabilidad, transparencia y verificabilidad.

El objetivo no es implementar toda la infraestructura de Stellar en Hub Mixteca, sino analizar qué características pueden ser útiles para la solución de Costuras de Tijaltepec.

## 2. Análisis técnico de Stellar

### 2.1 Stellar Consensus Protocol

Stellar utiliza el Stellar Consensus Protocol (SCP) para alcanzar consenso entre los participantes de la red.

El protocolo permite que los nodos lleguen a un acuerdo sobre el estado de la información registrada en la red.

Desde el punto de vista de calidad de software, esto permite analizar características como:

- Consistencia de la información.
- Fiabilidad.
- Disponibilidad.
- Integridad de los registros.
- Tolerancia ante fallos de determinados participantes.

Para Hub Mixteca, estos conceptos pueden servir como referencia para mantener información consistente sobre las operaciones que realmente requieran trazabilidad o verificación.

### 2.2 Activos digitales

Stellar permite trabajar con diferentes tipos de activos digitales.

La red puede representar activos relacionados con diferentes modelos de uso, incluyendo activos tradicionales y tokens.

Esta característica permite estudiar cómo una infraestructura digital puede representar operaciones de manera verificable.

En Hub Mixteca, esta posibilidad se considera únicamente como referencia para analizar operaciones relacionadas con información que pudiera requerir comprobación.

No se propone convertir automáticamente los productos textiles o los pedidos de Costuras de Tijaltepec en activos digitales.

### 2.3 Trazabilidad e integridad

Una característica importante de las redes blockchain es la posibilidad de mantener registros verificables de determinadas operaciones.

Para Hub Mixteca, esto puede relacionarse con la necesidad de mantener información confiable sobre los pedidos.

Por ejemplo, el sistema puede utilizar identificadores y estados de pedido para facilitar el seguimiento de una operación.

La utilización de blockchain debe limitarse a la información que realmente necesite características de integridad, trazabilidad o verificabilidad.

## 3. Gestión de código abierto

Stellar es desarrollado mediante un ecosistema de código abierto.

El código y la documentación pública permiten que diferentes participantes puedan estudiar, revisar y contribuir al desarrollo de la tecnología.

Para el proyecto Hub Mixteca, esta característica sirve como referencia para aplicar prácticas de ingeniería de software como:

- Control de versiones.
- Registro de cambios.
- Documentación.
- Revisión del código.
- Evidencias del desarrollo.
- Seguimiento de modificaciones.

Estas prácticas permiten mejorar la trazabilidad del propio desarrollo del proyecto.

## 4. Requerimientos de calidad

| Requerimiento | Referencia en Stellar | Aplicación en Hub Mixteca |
|---|---|---|
| Seguridad | Protección de operaciones y activos | Protección de información del taller y pedidos |
| Fiabilidad | Consenso entre participantes | Información consistente de los pedidos |
| Integridad | Registros verificables | Protección de información importante |
| Trazabilidad | Seguimiento de operaciones | Seguimiento mediante identificadores de pedido |
| Verificabilidad | Información registrada en la red | Verificación de datos seleccionados |
| Rendimiento | Procesamiento de operaciones | Sistema ligero y adecuado para dispositivos móviles |
| Mantenibilidad | Desarrollo y documentación pública | Código y documentación organizados |

## 5. Seguridad y fiabilidad

La seguridad es un aspecto fundamental en una red blockchain debido a que las operaciones pueden involucrar activos digitales y registros que deben mantenerse íntegros.

El análisis de Stellar permite considerar diferentes controles de calidad relacionados con:

- Validación de operaciones.
- Integridad de los datos.
- Consistencia de la información.
- Control de acceso.
- Registro de cambios.
- Manejo de errores.

Para Hub Mixteca, estos principios pueden aplicarse a la gestión de información de Costuras de Tijaltepec.

En particular, la información relacionada con pedidos debe mantenerse consistente para evitar errores en estados, fechas, anticipos y saldos.

## 6. Aplicación al proyecto Hub Mixteca

El problema principal identificado en Costuras de Tijaltepec es:

**Falta de canales de comercialización y visibilidad de mercado.**

La solución propuesta busca complementar la tienda física mediante un canal digital.

Entre las funciones consideradas se encuentran:

- Perfil digital verificable del taller.
- Información de productos.
- Fotografías optimizadas.
- Información de contacto.
- Seguimiento de pedidos.
- Identificación de los pedidos.
- Consulta del estado del pedido.

El análisis de Stellar permite relacionar estas funciones con requisitos de calidad como seguridad, fiabilidad, trazabilidad y verificabilidad.

## 7. Adaptación a las condiciones del proyecto

La tecnología debe adaptarse a las necesidades reales de Costuras de Tijaltepec y de los usuarios de la región Mixteca.

Por esta razón, la solución debe considerar:

- Uso desde dispositivos móviles.
- Interfaz sencilla.
- Bajo consumo de recursos.
- Fotografías optimizadas.
- Facilidad de navegación.
- Funcionamiento adecuado considerando las condiciones de conectividad.

El uso de blockchain no debe aumentar innecesariamente la complejidad del sistema.

## 8. Uso responsable de blockchain

Para Hub Mixteca se considera que blockchain puede ser útil cuando proporcione un beneficio concreto relacionado con:

- Integridad.
- Trazabilidad.
- Verificabilidad.

No se considera necesario almacenar fotografías, catálogos completos u otros archivos pesados directamente en blockchain.

La información visual puede utilizar mecanismos de almacenamiento adecuados y la blockchain puede reservarse para los datos que realmente requieran verificación.

## 9. Conclusión

El análisis técnico de Stellar permite identificar características de calidad relacionadas con consenso, seguridad, integridad, fiabilidad, trazabilidad y verificabilidad.

Estas características pueden utilizarse como referencia para establecer requisitos de calidad en Hub Mixteca y Costuras de Tijaltepec.

La solución debe mantener como prioridad la problemática real del taller: mejorar sus canales de comercialización y su visibilidad de mercado.

Por ello, blockchain debe incorporarse únicamente cuando exista un requisito que justifique su utilización y no simplemente por tratarse de una tecnología descentralizada.
