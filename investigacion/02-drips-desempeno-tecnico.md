# 02. Desempeño técnico — Drips

## 1. Introducción

Drips es un protocolo descentralizado construido sobre Ethereum que permite apoyar proyectos de software libre y sus dependencias mediante mecanismos de distribución de fondos.

Para este proyecto, el análisis de Drips permite identificar características de calidad relacionadas con la seguridad, fiabilidad, trazabilidad, transparencia y verificabilidad.

El análisis se realiza como referencia tecnológica para el proyecto Hub Mixteca y Costuras de Tijaltepec, sin establecer que Drips deba implementarse directamente en la solución.

## 2. Análisis técnico de Drips

### 2.1 Funcionamiento general

Drips permite distribuir fondos hacia proyectos de software libre, repositorios de GitHub, direcciones de Ethereum y otras listas de distribución.

El protocolo utiliza estructuras denominadas Drip Lists para establecer los destinatarios de los fondos.

Esta característica permite analizar la importancia de mantener información organizada y trazable dentro de un sistema digital.

### 2.2 Streaming de fondos

Drips utiliza el concepto de streaming para realizar transferencias continuas de fondos durante un periodo determinado.

Los streams permiten establecer reglas relacionadas con la cantidad de fondos que se distribuyen y el periodo durante el cual se realiza la distribución.

Para Hub Mixteca, este mecanismo se considera una referencia para analizar cómo un sistema puede manejar operaciones de manera programada y verificable.

No se propone utilizar streaming de fondos directamente para los pedidos de Costuras de Tijaltepec sin realizar previamente un análisis de requisitos, costos y riesgos.

### 2.3 Contratos inteligentes

Los contratos inteligentes son una parte fundamental de Drips porque contienen las reglas utilizadas para administrar determinadas operaciones del protocolo.

Debido a que estas operaciones pueden estar relacionadas con activos digitales, la seguridad y fiabilidad de los contratos son requisitos importantes.

En el contexto de Hub Mixteca, esto permite identificar la importancia de validar las reglas de negocio antes de incorporarlas a una solución tecnológica.

## 3. Gestión de código abierto

Drips mantiene documentación y código relacionados con su protocolo de manera pública.

El código abierto permite consultar los componentes del proyecto y facilita la revisión de su evolución mediante sistemas de control de versiones.

Para el proyecto Hub Mixteca, esta característica permite tomar como referencia prácticas como:

- Control de versiones.
- Registro de commits.
- Documentación.
- Revisión de cambios.
- Trazabilidad.
- Evidencias del desarrollo.

## 4. Requerimientos de calidad

| Requerimiento | Referencia en Drips | Aplicación en Hub Mixteca |
|---|---|---|
| Seguridad | Protección de contratos y operaciones | Protección de información y pedidos |
| Fiabilidad | Correcta ejecución de las reglas | Estados de pedidos consistentes |
| Trazabilidad | Registro de operaciones y cambios | Identificador y seguimiento de pedidos |
| Transparencia | Código y documentación públicos | Información clara para compradores |
| Verificabilidad | Operaciones basadas en reglas programadas | Verificación de información seleccionada |
| Mantenibilidad | Código organizado y versionado | Mantenimiento de la solución |
| Auditabilidad | Revisión y auditorías del protocolo | Revisión de cambios y evidencias |

Estas características corresponden al análisis de calidad realizado para este informe y no deben interpretarse como una lista oficial de métricas publicada por Drips.

## 5. Seguridad y fiabilidad

La seguridad es especialmente importante en Drips debido a que utiliza contratos inteligentes relacionados con la distribución de activos digitales.

La documentación oficial de Drips describe el uso de pruebas, fuzzing, auditorías externas y otros mecanismos para analizar la seguridad del protocolo.

Estas prácticas permiten identificar posibles errores y vulnerabilidades.

Para Hub Mixteca, los principios anteriores pueden aplicarse considerando:

- Integridad de los datos.
- Protección de la información.
- Control de modificaciones.
- Validación de datos.
- Registro de operaciones.
- Manejo de errores.

## 6. Aplicación al proyecto Hub Mixteca

El proyecto busca atender la falta de canales de comercialización y visibilidad de mercado de Costuras de Tijaltepec.

La solución contempla un perfil digital del taller y mecanismos para consultar y dar seguimiento a los pedidos.

Las características observadas en Drips permiten tomar como referencia:

- Trazabilidad.
- Transparencia.
- Verificabilidad.
- Seguridad.
- Registro de operaciones.

Estas características pueden utilizarse para definir requisitos de calidad del sistema.

Sin embargo, no todas las funciones requieren blockchain. El uso de esta tecnología debe justificarse únicamente cuando proporcione un beneficio concreto para el sistema.

## 7. Uso responsable de blockchain

Para el proyecto Hub Mixteca se considera que blockchain puede utilizarse cuando aporte:

- Integridad.
- Trazabilidad.
- Verificabilidad.

No se considera conveniente almacenar fotografías u otros archivos pesados directamente en blockchain.

Las fotografías y demás contenidos pueden utilizar mecanismos de almacenamiento adecuados, mientras que blockchain puede reservarse para información que realmente necesite verificabilidad.

## 8. Conclusión

El análisis técnico de Drips permite identificar características relacionadas con seguridad, fiabilidad, trazabilidad, transparencia y verificabilidad.

Estas características pueden utilizarse como referencia para establecer requisitos de calidad en Hub Mixteca y Costuras de Tijaltepec.

El uso de blockchain debe mantenerse limitado a las funciones donde aporte un beneficio real y no debe incorporarse únicamente por tratarse de una tecnología descentralizada.
